## 修复与优化

生产构建验收发现 UI 分包初始化顺序错误，已通过 strictExecutionOrder 修复并重新跑完整浏览器测试。路由懒加载和分包后最大生产 JS 包约 219 kB，不再有原 620 kB 单包警告。

AI 历史批量读取建议，列表数量限制下推数据库，周时长使用 SQL 聚合；模型和资讯响应采用流式字节上限、可取消总读取超时，避免超大/慢响应拖住执行器。周编辑版本冲突保留文字，AI 新执行器 ready 标记保证线程可见性。启动与备份统一读取单行 dotenv 字面值，修复引号/美元符号密码和 BCrypt 哈希不一致的问题，配置内容不会作为 shell 指令执行。

Docker Hub 网络 EOF 使用 Docker 官方 ECR 镜像集合解决；WSL 脚本挂载问题通过镜像内封装修复，未改变系统代理、证书信任或全局 WSL 集成设置。
