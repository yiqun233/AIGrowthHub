# 初版计划逐项核对

基线为用户已确认的 docs/development-plan.md V1.1。用户本轮明确要求补齐剩余功能，并确认“暂时没有服务器，先完成本机与部署包”，因此本轮不执行公网发布。下面区分“代码实现”和“外部验收”，不以测试夹具代替实际使用或真实模型调用。

| 计划项 | 代码/交付状态 | 核验依据或剩余条件 |
| --- | --- | --- |
| M0 环境、单仓库、固定源码路径、锁定依赖 | 已实现 | Java/Node/PostgreSQL 记录见 environment.md；Wrapper/npm 锁文件 |
| M1 目标/任务/日志、归档、延期、完成重开 | 已实现 | PostgreSQL API + 浏览器闭环 |
| 学习与开发时长分别记录、不重复累计 | 已实现 | activityType、休息 0 分钟、分类周统计 API |
| 首页任务、最近日志、最近 AI 与待确认建议 | 已实现 | 首页增加最近分析/建议入口 |
| 业务时区、预算和偏好设置 | 已实现 | IANA 时区持久化；日期保留；UTC/上海边界测试 |
| M2 多提供商、异步、快照、版本、重试、上限 | 已实现 | 十类协议模拟、全局活动上限、失败/恢复/证据校验 |
| 人工编辑/拒绝/确认、幂等/事务与来源失效 | 已实现 | 并发确认、触发器制造部分失败的回滚测试 |
| M3 JSON 导出和手动备份 | 已实现 | v3 覆盖 15 张业务表，不含密钥 |
| M3 七个自然日真实使用 | 待实际观察 | 已有试用清单；不能通过回填日期完成 |
| 真实模型权限、网络与输出质量 | 待真实凭据 | 本机尚未配置真实密钥，模拟协议不能证明真实模型可用 |
| M4 周计划与显式周任务归属 | 已实现 | 归档/日期、原子转移与 AI 跨周保护 |
| M4 周事实复盘、AI 草稿与人工确认 | 已实现 | 原文证据、采用前新鲜度、失败不覆盖文字、确认只读 |
| M4 独立成果管理 | 已实现 | 关联、编辑、归档、URL 校验及浏览器闭环 |
| M4 可重复备份恢复 | 已实现 | 新空库演练与逐行比对；非空库保护；记录见 environment.md |
| M5 两个官方 Release 源、去重/失败隔离 | 已实现 | 两源实际 200；模拟重复采集、XML 攻击、失败保留测试 |
| M5 按需摘要、收藏和候选转任务 | 已实现 | 真实证据验证、并发确认仅创建一个任务 |
| M6 单用户登录、CSRF、退出、会话过期 | 已实现 | Spring Security + 真实 API/浏览器；本机免登录仅允许回环监听 |
| M6 HTTPS、同源反代、缓存与健康检查 | 已实现并本机验证 | 本机私有 CA/TLS 验收；不等同真实公网证书 |
| M6 Docker/Compose 与 CI 构建检查 | 本机已构建并完成隔离容器验收 | 四镜像、健康检查、TLS、登录、自动备份及全表恢复通过；远端 CI 状态仍以 GitHub 为准 |
| M6 自动备份保留和独立副本 | 本机策略已实现；独立存储待配置 | 每日/每周、损坏修复、失败保留测试；没有远端存储账号 |
| 服务器、公网 DNS/证书、远端恢复、RPO/RTO | 按用户要求延期 | 暂无服务器/域名；不虚构公网部署或 SLA |
| 自动 12 周路线、月复盘、自由聊天、知识图谱 | 不在已确认初版范围 | 原计划明确延期；本轮未擅自增加 |
| 多用户、Redis/MQ/向量库、微服务/K8s | 不在范围 | 保持个人模块化单体 |

结论：初版约定的业务功能和本机/部署包代码已补齐；七天观察、真实模型与公网/独立存储仍有外部验收条件，不能将整张计划标为“全部验收完成”。功能与运行命令见 remaining-features.md、deployment.md；最终本地测试结果见 progress.md。
