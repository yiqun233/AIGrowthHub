## 导出

设置与数据 → 导出全部个人数据，或 GET /api/v1/exports。返回 JSON 附件，schemaVersion 为 `growthhub-export-v4`，exportedAt 为 UTC 时间；counts 对应 data 中 17 张业务表的记录数。保留原始日志、关联、阶段/周复盘快照、AI 输入快照、结果和确认状态。不包含环境变量、密钥、API 地址、请求幂等键和内部来源哈希。响应禁止缓存。

以 PostgreSQL REPEATABLE READ 事务获得同一数据快照。当前上限 20000 条记录、序列化后 50 MiB；超过返回 413，使用 bash scripts/backup.sh。JSON 导出用于个人留档和迁移检查，当前不提供 JSON 导入；数据库恢复仍按 docs/environment.md 的备份恢复步骤操作。

## 开始试用前

- 在服务端配置一家具备可用权限的提供商，设置页选择模型并保存。
- 使用一条可分享的真实学习记录生成分析，核对证据原文、安排时间与预算。
- 编辑草稿后确认，检查学习计划只出现一次；另试一次拒绝。
- 下载 JSON，检查近期记录和关联任务；保留数据库备份。
